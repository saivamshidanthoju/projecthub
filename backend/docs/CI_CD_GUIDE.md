# CI/CD Deployment Guide - ProjectHub

Our CI/CD pipeline is orchestrated via **GitHub Actions** and builds/deploys the backend application using Docker.

---

## 1. Pipeline Stages

The GitHub Actions workflow contains three main stages defined in `.github/workflows/ci-cd.yml`:

```
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│  Build & Test   │ ────>│ Docker Publish  │ ────>│   AWS Deploy    │
└─────────────────┘      └─────────────────┘      └─────────────────┘
```

1. **Build & Test**:
   - Checks out repository source code.
   - Installs node dependencies via `npm ci`.
   - Runs Jest test suites to verify auth/projects/tasks layers.
2. **Docker Publish** (Triggers only on merge to `main` branch):
   - Authenticates client against GitHub Container Registry (`ghcr.io`).
   - Builds container image using root `Dockerfile`.
   - Tags and publishes the image to the package registry.
3. **AWS Deploy** (Triggers only on merge to `main` branch):
   - Authenticates against AWS EC2 instance using SSH Key parameters.
   - Triggers `docker-compose pull` to fetch the fresh container layer.
   - Performs a zero-downtime rolling restart.

---

## 2. Secrets Mapping in GitHub Repository

Ensure the following credentials are configured in your GitHub Repository under **Settings > Secrets and variables > Actions**:

| Secret Name | Type | Description |
|---|---|---|
| `DEPLOY_HOST` | Secret | The public IP address or DNS domain of your AWS EC2 production server. |
| `DEPLOY_USER` | Secret | SSH user name (e.g. `ubuntu` or `ec2-user`). |
| `DEPLOY_KEY` | Secret | Private SSH Key to connect to AWS EC2. |
| `GITHUB_TOKEN` | Auto-provided | Automatically generated by GitHub Actions to authenticate Docker client with GHCR. |

## 3. Production Deployment Commands

On your AWS EC2 server, PM2 and Docker Compose orchestrate the processes. The production `docker-compose.yml` config defines:
```yaml
version: '3.8'

services:
  backend:
    image: ghcr.io/your-username/projecthub-backend:latest
    ports:
      - "5000:5000"
    environment:
      - NODE_ENV=production
      - PORT=5000
      - DB_HOST=your-rds-endpoint.amazonaws.com
      - DB_USER=postgres
      - DB_PASSWORD=your_rds_password
      - DB_NAME=projecthub
      - JWT_SECRET=your_production_secret_key
    restart: always
```
To check system status:
```bash
docker-compose ps
docker-compose logs -f backend
```
